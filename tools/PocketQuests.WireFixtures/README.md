# Serialized wire fixtures

Run `dotnet run --project tools/PocketQuests.WireFixtures -- contracts` to update only `contracts/wire-fixtures.json`, or use `scripts/Test-ClientContract.ps1` for the comparison gate. The fixture tool serializes real Domain projections through the Services contract mappings and catalog service with the API's camel-case/string-enum policy. It opens no database and calls no Identity service. Its canonical Services reference supplies the real public mappings and brings Data and Identity abstractions into the build dependency graph, so configure the same existing package feed or source references as the backend. It does not generate schemas or enumerate operations.

Actual endpoint OpenAPI is generated by API contract tests. See `docs/api-contract.md` for the combined gate and intentional update procedure.
