# @honeydrunk/ui-tokens

Private, unpublished, platform-neutral `Theme` contract and `foundation` geometry/typography defaults. Apps own every palette. `resolveTheme(theme)` supplies defaults for new optional fields without mutating the supplied object.

See the [token compatibility contract](../../README.md#token-compatibility), [testing plan](../../docs/testing.md), and [changelog](CHANGELOG.md). No React or platform runtime dependency.
