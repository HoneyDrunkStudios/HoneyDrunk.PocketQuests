# @honeydrunk/ui-native

Private, unpublished, themeable React Native primitives. Hosts supply React 19.2 / React Native 0.86 and a complete app theme through `ThemeProvider`. Browser hosts adapt React Native to React Native Web.

Exports: ThemeProvider, useTheme, Button, Label, Card, Input, Loading, Notice, Badge, Progress, createStyles, buttonAppearance, focusAppearance, and the ButtonProps/InputProps/BadgeProps/ProgressProps types. See the [usage and compatibility notes](../../README.md), [testing plan](../../docs/testing.md), and [changelog](CHANGELOG.md).

Navigation, domain policy, authentication, content and assets belong to the consumer.
